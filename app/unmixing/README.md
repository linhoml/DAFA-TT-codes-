# Unmixing

## 菜单结构

```
Unmixing
 ├─ Hapke model
 │   ├─ 加载高光谱图像
 │   ├─ 加载辅助立方体
 │   ├─ 加载端元反射率 Excel…
 │   ├─ 单光谱计算
 │   ├─ 图像处理
 │   ├─ 显示丰度图…
 │   ├─ 显示 RMSE 图
 │   └─ 导出 k(λ)…
 └─ Sparse unmixing   （暂不改动）
```

## 量纲约定（重要）

| 数据 | 物理量 | 说明 |
|------|--------|------|
| 高光谱图像像元 | 辐亮度因子 **I/F** | CRISM 等产品 |
| 端元 Excel 光谱 | 反射率因子 **REFF** | 实验室矿物光谱 |
| 辅助立方体 band1 | 太阳入射角 **i** | 度 |

换算关系：

```
I/F = REFF × cos(i)
REFF = I/F / cos(i)
```

- 由端元 REFF 反演 k(λ) / SSA 时在 **REFF** 空间进行（实验室几何角）。
- 单光谱 / 图像解混时：Hapke 前向得到混合物 REFF，再乘以该像元 `cos(i)` 得到 **I/F**，与图像观测比较。

## Hapke model 流程

1. **加载高光谱图像**（I/F）
2. **加载辅助立方体**（band1 入射角 i，band2 观测角 e）
3. **加载端元 REFF Excel** → 输入 ρ / n / D → 反演 k(λ)
4. **单光谱计算**
   - 进入点击模式后，在左侧假彩色图点选像元
   - 用 Excel 端元解算该像元矿物质量比例（拟合在 I/F 空间）
   - **右侧上方**显示：原始 I/F（黑）+ 拟合 I/F（红）
5. **图像处理**：整图丰度图（可空间抽样；逐像元用辅助立方体入射角）

# Unmixing

## 菜单结构

```
Unmixing
 ├─ Hapke model
 │   ├─ 加载高光谱图像
 │   ├─ 加载辅助立方体
 │   ├─ 加载端元反射率 Excel…
 │   ├─ 单光谱计算
 │   ├─ 图像处理
 │   ├─ 显示丰度图…
 │   ├─ 显示 RMSE 图
 │   └─ 导出 k(λ)…
 └─ Sparse unmixing   （暂不改动）
```

## 量纲约定（重要）

| 数据 | 物理量 | 说明 |
|------|--------|------|
| 高光谱图像像元 | 辐亮度因子 **I/F** | CRISM 等产品 |
| 端元 Excel 光谱 | 反射率因子 **REFF** | 实验室矿物光谱 |
| 辅助立方体 band1 | 太阳入射角 **i** | 度 |

换算关系：

```
I/F = REFF × cos(i)
REFF = I/F / cos(i)
```

- 由端元 REFF 反演 k(λ) / SSA 时在 **REFF** 空间进行（实验室几何角，默认 i=30°, e=0°）。
- 单光谱 / 图像解混时：Hapke 前向得到混合物 REFF，再乘以该像元 `cos(i)` 得到 **I/F**，与图像观测比较。

## 端元 Excel 排布

单表，第 1 列为波长相关，第 2 列起为各矿物端元：

| Excel 行 | 内容 |
|---------|------|
| 第1行 | 矿物名称（标题） |
| 第2行 | 光谱ID |
| 第3行 | 平均粒径 D (μm) |
| 第4行 | 密度 ρ (g/cm³) |
| 第5行 | 折射率实部 n |
| 第6行及之后 | 第1列波长，其后各列为 REFF |

加载后会打开 **Hapke 端元物理参数** 面板：预填矿物名称（第1行）及 D/ρ/n；每个矿物可单独修改 REFF 测量入射角/发射角/相位角（默认 30°/0°/30°）。面板最后一行为 **图像背景** 端元（无特征像元平均 **I/F**；i/e/g 为其均值；ρ=3，n=1.8，D=10 μm）。Excel 矿物解混时用 `I/F=REFF×cos(i)`；**图像背景不再乘 cos(i)**。用「选用」勾选参与解混的端元。

## Hapke model 流程

1. **加载高光谱图像**（I/F）
2. **加载辅助立方体**（band1 入射角 i，band2 观测角 e）
3. **加载端元 REFF Excel** → 参数面板确认/勾选 → 反演 k(λ)
4. **单光谱计算**（仅对已勾选端元）
   - 左侧假彩色图点选像元
   - 右侧上方：原始 I/F（黑）+ 拟合 I/F（红）
5. **图像处理**：整图丰度图（仅已勾选端元；可空间抽样）

# Unmixing

## 菜单结构

```
Unmixing
 ├─ Hapke model
 │   ├─ 加载高光谱图像
 │   ├─ 加载辅助立方体
 │   ├─ 加载端元反射率 Excel…
 │   ├─ 单光谱计算
 │   ├─ 图像处理
 │   ├─ 显示丰度图…
 │   ├─ 显示 RMSE 图
 │   └─ 导出 k(λ)…
 └─ Sparse unmixing   （暂不改动）
```

## Hapke model 流程

1. **加载高光谱图像**（反射率 / I/F）
2. **加载辅助立方体**（band1 入射角 i，band2 观测角 e）
3. **加载端元反射率 Excel** → 输入 ρ / n / D → 反演 k(λ)
4. **单光谱计算**
   - 进入点击模式后，在左侧假彩色图点选像元
   - 用 Excel 端元解算该像元矿物质量比例
   - **右侧上方**显示：原始光谱（黑）+ 拟合光谱（红）
5. **图像处理**：整图丰度图（可空间抽样）

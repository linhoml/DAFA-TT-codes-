# Unmixing

## 菜单结构

```
Unmixing
 ├─ Hapke model
 │   ├─ 加载高光谱图像
 │   ├─ 加载辅助立方体
 │   ├─ 加载端元反射率 Excel…
 │   ├─ 单光谱计算
 │   ├─ 图像处理
 │   ├─ 显示丰度图…
 │   ├─ 显示 RMSE 图
 │   └─ 导出 k(λ)…
 └─ Sparse unmixing   （暂不改动）
```

## Hapke model 流程

1. **加载高光谱图像**（反射率 / I/F）
2. **加载辅助立方体**（band1 入射角 i，band2 观测角 e；可与高光谱同尺寸）
3. **加载端元反射率 Excel**
   - 第 1 列波长 (μm/nm)，其后每列一个矿物反射率（表头=矿物名）
   - 弹出表格输入每个矿物：**密度 ρ**、**折射率实部 n**（全波段一个数）、**平均粒径 D**
   - 以及实验室测量角，用于从反射率反演 **k(λ)**
4. **单光谱计算**：点击像元 → 用该像元辅助几何 + Hapke 非线性最小二乘求质量丰度  
5. **图像处理**：整图（可空间抽样），逐像元几何取自辅助立方体
